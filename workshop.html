ASTRA × TRIPO CLI / A REPRODUCIBLE WORKFLOW

From a terminal prompt to a playable world.

Astra built Cloudgarden using TypeScript, Vite and Three.js. Tripo generated the physical models through its local CLI. This lantern traces one real generation into the game.

1. Set up once

Sign up through Tripo’s official site, then install and authenticate. The creator’s existing account was already authenticated.

npm install -g tripo-cli
tripo login
tripo doctor

Installation is free. Model generation uses Tripo credits.

2. Validate, then generate

The dry run checks the request without generating. The second command creates the model and downloads its files.

4. Place it in Three.js
// src/config.ts — include the local GLB
export const ASSET_IDS = ["lantern", /* other assets */];

// src/world.ts — same generated model, near spawn
this.place("lantern", 2.7, 11, 1.5, -0.4);
Cloudgarden’s loader reads local GLBs. Its placement helper scales the asset and finds the terrain height. The game needs no Tripo credentials at runtime.
